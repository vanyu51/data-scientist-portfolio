# Прогноз клика по рекламе (CTR): классификация + калибровка вероятностей

Классический ad-click датасет — с высококардинальными категориальными признаками, сравнением ядер SVC и, впервые в портфолио, полноценной **калибровкой вероятностей**.

## Что делал

- Обнаружил, что `hour` на деле составной признак (год+месяц+день+час склеены в одно число) — декомпозировал его на отдельные интерпретируемые столбцы
- Нашёл скрытые пропуски, замаскированные под `-1`, там где явных `NULL` не было
- Подобрал кодировку под кардинальность признака: OHE для низкой кардинальности, `TargetEncoder` для высокой (`site_id`, `device_id` с тысячами уникальных значений)
- Впервые сравнил **SVC с разными ядрами** (`linear`, `rbf`, `sigmoid`) против `LogisticRegression` — линейные модели оказались быстрее и не хуже по качеству, ядерные SVC не вошли в топ по PR-AUC
- Подбирал гиперпараметры через `GridSearchCV` на уменьшенной подвыборке (10 000 строк), чтобы уложиться по времени, а затем валидировал лучшую конфигурацию на полных данных
- Впервые применил **калибровку вероятностей**: сравнил модель до/после калибровки по **Brier score**, **ECE** и **MCE** — редко используемым, но более информативным метрикам качества вероятностных предсказаний, чем просто Accuracy

## Метрики

Финальная модель — **LogisticRegression (C=0.1, l2, class_weight='balanced')**:
- **PR-AUC = 0.40** (Dummy — 0.17)
- После калибровки: **Brier score снизился с 0.197 до 0.125**, **ECE — с 0.25 до 0.01**

## Стек

scikit-learn: `SVC`, `TargetEncoder`, `GridSearchCV`, `CalibratedClassifierCV`, калибровочные метрики (Brier, ECE, MCE)
