# Портфолио проектов по Data Science

Мои проекты по пути от SQL к ML: от агрегатных запросов до бустингов с калибровкой вероятностей, A/B-тестов и пайплайнов в Airflow. Каждая папка это отдельный проект со своим README, где описаны задача, подход, результат и ограничения.

| Проект | Результат |
|---|---|
| [07 — Отток клиентов](./07-ml-classification-coffee-churn) | PR-AUC 0,72 на тесте при сильном дисбалансе классов |
| [10 — Кредитный скоринг](./10-ml-credit-scoring) | Recall 0,98 при пороге 0,04, подобранном под три бизнес-требования; изотоническая калибровка |

| [17 — Прогноз продаж](./17-ml-airflow-sales-forecast) | MAE 1 316 (около 8% от средних продаж), еженедельный прогноз в Airflow |

## О подходе

В каждом проекте иду от постановки задачи и EDA до подбора гиперпараметров, интерпретации модели и перевода метрик качества в бизнес-язык: стоимость ошибок, подбор порога, экономический эффект. Отдельное внимание уделяю защите от утечек данных (разбиение по времени и по группам, расчёт признаков только по прошлому) и честному описанию ограничений каждого проекта.
