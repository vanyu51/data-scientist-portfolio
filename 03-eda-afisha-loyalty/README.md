# Анализ факторов повторных покупок: SQL + Python

Полный цикл от SQL-выгрузки до проверки продуктовых гипотез: какие признаки первого заказа связаны с вероятностью, что пользователь вернётся за повторной покупкой.

## Что делал

- Выгружал данные напрямую SQL-запросом в pandas через `SQLAlchemy`, включая оконную функцию `LAG` внутри запроса для расчёта интервала между покупками
- Провёл полную предобработку: перевод выручки из двух валют в одну через `merge` с таблицей курсов, поиск неявных дубликатов по паре (`user_id`, `order_ts`), оптимизация типов данных (`int8`, `float32`, `category`) для экономии памяти
- Построил профили пользователей через `groupby.agg` с несколькими агрегирующими функциями сразу
- Впервые применил **`phik`-корреляцию** — коэффициент, который в отличие от Пирсона одинаково хорошо работает и с числовыми, и с категориальными признаками. Это позволило в одной матрице сравнить влияние жанра мероприятия, устройства, региона и числовых метрик на возврат
- Сформулировал две продуктовые гипотезы (влияние типа мероприятия и активности региона на удержание) и проверил их на данных — обе не подтвердились, что само по себе важный результат

## Ключевые находки

- 61.7% пользователей делают 2+ заказа, 29% — 5+. Сегмент, тип устройства и регион первого заказа **слабо** влияют на возврат (диапазон 0.55–0.65 везде)
- Самая сильная связь с повторными покупками — количество билетов в заказе: у пользователей с 2–3 билетами доля возврата 0.74, у покупающих 5+ билетов — всего 0.19
- `phik`-корреляция подтвердила выводы EDA количественно: `tickets_avg` (0.65) и `days_between` (0.40) — главные предикторы числа заказов

## Стек

PostgreSQL (выгрузка), pandas, `phik`, matplotlib/seaborn
