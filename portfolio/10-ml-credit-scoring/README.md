# Поведенческий кредитный скоринг: временные ряды + бизнес-метрики

Самый комплексный проект в портфолио: прогноз просрочки платежа на 90+ дней с учётом временной структуры данных, кастомными бизнес-метриками и калибровкой под конкретные ограничения бизнеса.

## Что делал

- Собрал таблицу из 8 источников (транзакции, кредитный рейтинг, макроэкономика и др.) с учётом **временной оси**: для каждой пары (клиент, дата скоринга) присоединял именно тот срез данных, который был известен на эту дату — написал функцию `add_last_known`, чтобы исключить утечку информации из будущего
- Сформировал целевую переменную через скользящее окно: "случится ли просрочка 90+ дней в ближайшие 12 месяцев" — с явным исключением строк, где дефолт уже случился к моменту скоринга
- Провёл feature engineering на основе доменной логики (долговая нагрузка, свободные деньги, волатильность трат через `rolling`) — по итогу именно эти признаки, а не сырые данные, оказались важнейшими
- Разбил данные **по времени, а не случайно**: последние 12 месяцев — тест, предпоследние 12 — калибровка, остальное — обучение. Использовал `GroupTimeSeriesSplit` для кросс-валидации без утечки
- Сравнил способы балансировки классов: `class_weight`, oversampling, undersampling, SMOTE — через `imbalanced-learn` Pipeline
- Впервые подбирал гиперпараметры через **Optuna** — оптимизировал не абстрактную метрику, а конкретный бизнес-показатель (missed defaults rate)
- Откалибровал модель (`isotonic`) и подобрал порог классификации не "по умолчанию 0.5", а под три одновременных бизнес-ограничения: approval rate ≥ 65%, default rate ≤ 2%, missed defaults rate ≤ 4%
- Посчитал важность признаков через `feature_importances_` и связал её с бизнес-интерпретацией

## Метрики

Финальная модель — **Random Forest (tuned через Optuna)**, порог 0.04:
- Missed defaults rate снижен с 0.470 до **0.073** после тюнинга
- Все три бизнес-ограничения выполнены на калибровочной и тестовой выборке

## Стек

scikit-learn, `imbalanced-learn` (SMOTE, RandomOverSampler), `Optuna`, `GroupTimeSeriesSplit`, кастомные scorer'ы, калибровка вероятностей
