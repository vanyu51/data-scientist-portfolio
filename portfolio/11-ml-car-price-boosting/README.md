# Оценка стоимости автомобиля: градиентный бустинг + SHAP

Регрессия с асимметричной ценой ошибки (продавцу дороже занизить цену, чем завысить) — первый проект в портфолио, где сравниваю все три основных бустинга и объясняю предсказания через SHAP.

## Что делал

- Сравнил **XGBoost, CatBoost и LightGBM** на одинаковых данных с замером времени обучения — LightGBM оказался в ~20 раз быстрее CatBoost при сопоставимом качестве
- Спроектировал **кастомные бизнес-метрики** вместо стандартных: `Overpricing Rate` (доля сделок с завышением цены на 20%+) и `Underpricing Loss` (суммарные недополученные деньги от заниженных цен) — и в итоге выбирал модель по ним, а не по чистому MAE
- Использовал встроенные категориальные кодировщики бустингов вместо ручного OHE — с обоснованием, почему это уместно именно для этого семейства моделей
- Подбирал гиперпараметры для каждой из трёх моделей отдельно через **Optuna**
- Впервые применил **SHAP** (`TreeExplainer` + `summary_plot`) для интерпретации: все три модели независимо выделили один и тот же топ-5 признаков, что стало дополнительной проверкой согласованности моделей
- Разобрал ошибки предсказания по срезам (бренд, регион) и связал их с бизнес-метриками — нашёл регионы с высоким риском переплаты и отдельно регионы с риском упущенной выгоды

## Метрики

Финальная модель — **CatBoostRegressor** (learning_rate≈0.04, depth=4):
- **MAE = 79 242**, **R² = 0.85** на валидации
- **Underpricing Loss = 17.4 млн ₽** — наименьший среди трёх моделей
- На тестовой выборке разница с валидацией минимальна, переобучения нет

## Стек

CatBoost, XGBoost, LightGBM, `Optuna`, `SHAP`, `phik`
