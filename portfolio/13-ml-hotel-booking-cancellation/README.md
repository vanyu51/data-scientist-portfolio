# Прогноз отмены бронирования отеля: классификация + NLP + экономический эффект

Пожалуй, самый разноплановый проект в портфолио: SQL-выгрузка, обработка текстовых отзывов, шесть моделей классификации и, что важнее всего, расчёт денежного эффекта от внедрения модели.

## Что делал

- Выгружал данные напрямую из PostgreSQL через `SQLAlchemy`
- Разбирался с дубликатами на разных уровнях осмысленно: дубликаты по тексту отзыва (44% совпадений) оказались особенностью генерации данных, а не проблемой — не стал их удалять бездумно, только проверив происхождение
- Нашёл и исправил опечатку в категориальном признаке (`"не выбрант"` → `"не выбран"`), обнаружил и поправил аномальные значения через сверку со средней ценой (числа вроде 100/200/300 в поле "количество взрослых" оказались опечаткой×100)
- Впервые применил обработку текста: **NLTK** для удаления стоп-слов и **TF-IDF** для векторизации отзывов клиентов как признака модели
- Собрал единую таблицу с учётом времени — для каждой брони подтягивал именно предыдущий по времени отзыв того же клиента, а не любой
- Сравнил 6 моделей включая три бустинга, подобрал гиперпараметры лучшей через **Optuna**, откалибровал и подобрал порог не по стандартной метрике, а по максимуму кастомной экономической метрики
- Спроектировал **экономическую метрику IR (incremental revenue)** — учитывает стоимость ложных срабатываний, потери от нераспознанных отмен и выгоду от верных предсказаний в рублях, а не в абстрактных единицах качества
- Довёл проект до конца: посчитал итоговый экономический эффект внедрения модели (изменение загрузки отеля, доли отмен, ROI) — а не просто зафиксировал метрики классификации

## Метрики

Финальная модель — **CatBoost** (глубина 3–6, оптимизация под IR):
- **Precision = 0.63**, **Recall = 0.76** при пороге 0.31
- **Относительный IR = +64%** по сравнению с ситуацией без модели
- Доля отмен после внедрения снижена до 3.9% (целевой порог — 10%)

## Стек

CatBoost, XGBoost, LightGBM, `SQLAlchemy`, `NLTK`, `TfidfVectorizer`, `SHAP`, `Optuna`, кастомная экономическая метрика
