# Анализ рынка общепита: EDA + рекомендации

Исследование более 8000 заведений общественного питания: структура рынка по категориям, районам, ценам и рейтингам — с прицелом на практические выводы для потенциального открытия точки.

## Что делал

- Объединял два источника (`rest_info` + `rest_price`) через `merge`, при этом часть заведений не имела ценовых данных — обосновал и применил разные стратегии обработки пропусков для разных столбцов (`unknown` вместо удаления, где пропуск сам по себе информативен)
- Искал неявные дубликаты нестандартным способом: нормализация названия + адреса (нижний регистр, удаление разделителей через regex) и сравнение по составному ключу — так нашёл дубликаты, которые не ловились обычным `duplicated()`
- Сделал полноценный EDA по 8 самостоятельным бизнес-вопросам с визуализацией под каждый: распределение по категориям и районам, доля сетевых заведений, аномалии в посадочных местах, рейтинги, топ-15 сетей, зависимость среднего чека от удалённости от центра
- Использовал `phik`-матрицу, чтобы понять, что сильнее всего связано с рейтингом заведения — оказалось, ценовая категория, а не сетевой статус или район

## Ключевые находки

- Несетевых заведений почти вдвое больше сетевых, но по категориям картина разная: булочные на 61% сетевые, бары — только на 22%
- Средний чек в ЦАО почти вдвое выше, чем в ЮВАО, что подтверждает эффект удалённости от центра
- Рейтинг слабо зависит от большинства измеримых факторов — самая сильная связь всё равно лишь умеренная

## Стек

pandas, `phik`, matplotlib/seaborn, работа с неявными дубликатами через нормализацию строк
