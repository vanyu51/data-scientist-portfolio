# Классификация возрастной группы пользователя: мультиклассовая модель

Определение возрастной группы по поведению пользователя (визиты, реклама, устройства) — задача с несколькими источниками данных и требованием к конкретному уровню recall для одного из классов.

## Что делал

- Собрал единый датасет из 6 разрозненных источников через последовательные `merge`/`join`, включая построение агрегированных профилей активности (`groupby.agg` с `mean`/`median` по категориям + подсчёт сессий)
- Извлёк признак сезонности из временного диапазона всего в 14 дней — оценил, что можно выжать из данных не более чем деление на будни/выходные, и заложил это в признаки
- Впервые применил **методы отбора признаков как обёртки**: сравнил `SelectKBest` (по mutual information) и `RFE` — `SelectKBest` показал лучший результат (F1-macro 0.676 на 26 признаках из исходных 53)
- Сравнил multinomial / OvR / OvO стратегии `LogisticRegression` для мультикласса и добавил `LinearSVC` как альтернативу
- Подобрал не общий порог, а специально настроенный **порог для одного конкретного класса** (несовершеннолетние) под целевой recall = 0.90, при этом сохранив приемлемый precision — из соображений, что для этого класса цена ошибки asymmetричная
- Сохранил не просто модель, а полный артефакт: pipeline + порог + все вспомогательные функции трансформации, чтобы предсказание воспроизводилось один в один

## Метрики

Финальная модель — **multinomial LogisticRegression (C=1)**:
- **Accuracy = 0.780**, **Precision-macro = 0.76**
- Recall для класса риска (несовершеннолетние) выведен на 0.90 через подбор индивидуального порога

## Стек

scikit-learn: `SelectKBest`, `RFE`, `OneVsRestClassifier`/`OneVsOneClassifier`, `StratifiedKFold`, `phik`, `joblib`
