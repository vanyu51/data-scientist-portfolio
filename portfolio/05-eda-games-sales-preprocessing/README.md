# Предобработка датасета продаж видеоигр: pandas

Фокус проекта — не столько анализ, сколько качественная предобработка "грязных" данных: скрытые проблемы типов, замаскированные пропуски, неявные дубликаты.

## Что делал

- Столкнулся с тем, что часть столбцов, которые должны быть числовыми, были прочитаны как `object` — оказалось, внутри спрятаны текстовые значения-заглушки (`'tbd'`, `'unknown'`). Нашёл их через `pd.to_numeric(..., errors='coerce')` в комбинации с маской, а не просто `.astype(float)`, который бы упал с ошибкой
- Выстроил разные стратегии для разных пропусков осознанно: строки без года/названия/жанра удалил (их < 2% и без этих полей строка бесполезна для анализа), а пропуски в оценках критиков/пользователей (>50%) заменил явной меткой, чтобы не терять большую часть датасета
- Нашёл неявные дубликаты в жанрах игр из-за разного регистра написания (`Action` vs `ACTION`) — нормализовал и только затем убрал дубликаты
- Провёл категоризацию числовых оценок через `pd.cut` с явными границами и подписанными интервалами

## Ключевые находки

- После предобработки удалено ~3% строк — задокументировано на каждом шаге, сколько и почему
- 235 дубликатов, из них 56 стали видны только после нормализации регистра — без этого шага они остались бы в данных

## Стек

pandas: `pd.to_numeric` с обработкой скрытых нечисловых значений, `pd.cut`, работа с неявными дубликатами
